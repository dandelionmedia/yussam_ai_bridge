지침 · Gem · 프로젝트 · 스킬로 다시 쓰기

강의가 끝나면 아무것도 남지 않는 것이 자산 격차입니다. 이 가이드는 복사한 프롬프트를 내 문서로 남기는 법(원본), 그것을 지침·Gem·프로젝트·스킬로 옮겨 다음 대화에서 자동으로 쓰는 법(사본), 그리고 이 플랫폼의 보관 기능을 설명합니다.

원칙 하나그릇 5종지침 작성법만드는 절차플랫폼의 보관 기능판정 퀴즈프롬프트 3종
이 가이드의 한 줄

원본은 문서에, 사본은 도구에
도구는 바뀌어도 내 자산은 남는다

※ 도구별 메뉴 이름은 2026-09 기준입니다. 이름은 바뀌지만 "지침 · 지식 파일 · 반복 절차"라는 세 가지 그릇의 구조는 같습니다. 처음 설정할 때 최신 안내를 한 번 확인하세요.

1. 원칙 하나 — 원본은 문서에, 사본은 도구에

도구 안에만 두면 요금제·기능 변경 때 통째로 잃습니다. 내가 소유한 문서(구글 문서·드라이브·PDF)가 원본이고, 챗봇의 지침·프로젝트·스킬은 그 원본을 옮겨 놓은 사본입니다. 모든 보관본에는 제목·작성일·"ⓒ AI콘텐츠마케팅연구소 유쌤클래스 김유성 대표 · PK-PDCA 브릿지" 표기가 자동으로 붙습니다.

2. 그릇 5종 — 어디에 무엇을 담나

그릇담는 것잘 맞는 경우주의
문서·클라우드 폴더(원본)프롬프트 원문, 결과물, 한 장 요약모든 경우. 가장 먼저제목·날짜·ⓒ 표기, 폴더 이름은 업무 기준
챗GPT 맞춤 설정 · 프로젝트 · GPTs말투·규칙(지침), 자료(프로젝트 파일), 공유용 도우미(GPTs)챗GPT를 주로 쓰는 개인·팀GPTs 공개 범위 확인, 개인정보 올리지 않기
제미나이 Gem역할·지침·참고 파일을 묶은 맞춤 도우미구글 문서·드라이브 자료가 많은 경우파일 갱신 시 Gem도 다시 확인
클로드 프로젝트 · 스킬프로젝트: 지침+지식 파일. 스킬: 반복 절차(문서 규격·점검표)같은 규격의 문서를 반복 생산할 때스킬은 절차만, 사실 자료는 지식 파일로
웹앱(바이브 코딩) — 조건부여러 사람이 같은 절차를 쓰는 도구혼자 쓰지 않고, 개인정보가 없고, 고장 시 고칠 사람이 있을 때만세 조건 중 하나라도 아니면 위 넷으로 충분
지침 · 지식 파일 · 절차, 세 가지를 가른다

지침은 항상 적용할 짧은 규칙(말투·금지·형식), 지식 파일은 사실 자료(메뉴판·규격·지난 글), 절차(스킬)는 매번 같은 순서로 하는 일(점검표·문서 규격)입니다.

무엇이 지침이고 무엇이 대화로 남는지 헷갈리면 "세 번 이상 반복해서 말했는가"를 기준으로 삼습니다. 세 번이면 지침입니다.

3. 지침 작성법 (Instructions) — 8줄 템플릿

지침은 짧아야 지켜집니다. 아래 중괄호 만 채우면 챗GPT 맞춤 설정, 제미나이 Gem 지침, 클로드 프로젝트 지침 어디에나 그대로 붙일 수 있습니다.

[내 역할·업종]: {예: 분당의 반찬 가게 사장}
[고객]: {예: 40~60대 주부, 단골 위주}
[말투]: {예: 존댓말, 짧은 문장, 이모지 없음}
[항상 지킬 것]: 없는 사실 쓰지 않기 · 가격·일정은 내가 준 것만 · 고객 이름 쓰지 않기 · 과장 표현 금지
[자주 하는 일]: {1. 오늘의 반찬 게시글 2. 예약 답변 문자 3. 행사 안내}
[결과 형식 기본값]: {예: 제목 1줄 + 본문 3문장 + 주문 방법 1줄}
[하지 말 것]: {예: 경쟁 가게 언급, 건강 효능 단정}
[모를 때]: 질문을 먼저 하고, 확인 못 한 것은 "확인 필요"로 표시
  1. 역할·고객·말투를 먼저.
    AI가 누구로서 누구에게 말하는지가 결과의 절반입니다.
  2. 규칙은 5개 이내, 금지는 구체적으로.
    "과장하지 마"보다 "최고·무조건·100% 쓰지 않기"가 지켜집니다.
  3. 자료는 지침에 넣지 않는다.
    메뉴판·규격·지난 글은 지식 파일로. 지침에 넣으면 길어져 무시됩니다.
  4. 모를 때의 행동을 정한다.
    "질문 먼저, 확인 못 한 것은 표시"가 있어야 지어내지 않습니다.

※ 안전 문구 네 가지(불확실성·질문 우선·출처·과장 금지)는 전문 프롬프트에도 자동으로 붙습니다. 지침에는 그중 항상 필요한 것만 넣습니다.

4. 만드는 절차 — 도구가 달라도 여섯 단계는 같다

1 · 원본 저장

보관함의 프롬프트를 하나씩 복사해 내 구글 문서에 붙여 넣기 (전체 내보내기는 유료 가입자 기능)
표시
제목·날짜·ⓒ가 붙은 문서가 내 드라이브에 있다.

2 · 지침 8줄 쓰기

3절 템플릿 또는 7절 메타 프롬프트로
표시
8줄 이내, 금지 표현이 구체적.

3 · 그릇 고르기

주로 쓰는 도구 하나에만 먼저
표시
챗GPT 맞춤 설정·프로젝트 / 제미나이 Gem / 클로드 프로젝트 중 하나.

4 · 지식 파일 올리기 (Knowledge)

사실 자료만, 최신 것만, 개인정보 없이
표시
파일 이름에 날짜. 3~5개로 시작.

5 · 테스트 2회

자주 하는 일 두 가지를 실제로 시켜 본다
표시
지침을 어긴 곳이 있으면 지침을 고친다(대화에서 고치지 않는다).

6 · 절차는 스킬·점검표로 (Skill · Checklist)

매번 같은 순서의 일은 절차 문서로 분리
표시
클로드 스킬, 또는 프로젝트 안의 "절차.md". 문서 규격·점검표가 대표 예.

메뉴 이름(2026-09 기준) — 챗GPT: 설정 → 맞춤 설정 / 프로젝트 / GPT 만들기. 제미나이: Gem 관리자 → 새 Gem. 클로드: 프로젝트 → 프로젝트 지침·지식, 설정 → 스킬. 이름이 바뀌면 가이드 「클로드 AI 활용법」의 최신 절을 봅니다.

5. 이 플랫폼의 보관 기능

  1. 복사 = 보관.
    어느 화면에서든 "복사" 단추를 누르면 클립보드에 복사되는 동시에 내 기기의 프롬프트 보관함에 쌓입니다(가입 없음, 이 기기에만 저장).
  2. 보관함(메뉴 프롬프트 → 내 프롬프트 보관함).
    모아 둔 프롬프트를 하나씩 다시 복사해 내 문서에 붙여 넣습니다. "구글 문서로 열기"·"파일로 내려받기"·"전체 복사" 같은 전체 내보내기는 유료 가입자 기능입니다.
  3. 세션 결과물의 보관.
    세션 앱 마지막 단계의 "구글 문서로 보관"·"인쇄·PDF 저장"은 제목·날짜·ⓒ를 자동으로 붙입니다.
  4. 다음 단계.
    구글 드라이브 자동 저장(문서·시트)은 2단계 기능입니다. 지금은 "복사 → 새 문서 → 붙여넣기" 세 동작으로 같은 결과를 냅니다.

※ 보관함은 브라우저 저장소를 쓰므로 기기를 바꾸면 보이지 않습니다. 그래서 원본은 반드시 구글 문서나 파일로 남깁니다.

아래는 내가 지난 {기간} 동안 복사해 둔 프롬프트 목록입니다. 자산으로 정리해 주세요.

[보관함에서 하나씩 복사해 붙여 넣은 프롬프트 목록]

해 줄 것:
1. 비슷한 것끼리 묶고 묶음마다 이름을 붙인다(업무 기준, 5개 이내).
2. 묶음마다 대표 프롬프트 1개를 고르고, 반복되는 부분을 { } 변수로 바꾼 템플릿을 만든다.
3. 지침으로 옮길 문장(매번 반복된 규칙·말투)과 대화창에 남길 문장을 나눈다.
4. 표로 정리: 묶음 · 템플릿 · 지침으로 옮길 것 · 다음에 쓸 상황.
마지막에 "가장 먼저 지침으로 만들 것 1개"를 추천하고 이유를 한 줄로.

다. 지침이 잘 작동하는지 점검하기

아래 지침을 적용한 상태에서, 내가 자주 하는 일 {예: 오늘의 반찬 게시글}을 시켜 볼게요.
지침: {지침 8줄 붙여 넣기}
요청: {실제 요청 한 줄}

결과를 낸 뒤, 지침의 각 줄을 지켰는지 ✓/✕ 표로 스스로 점검하고, ✕가 있으면 지침의 어느 줄을 어떻게 고치면 되는지 제안하세요.

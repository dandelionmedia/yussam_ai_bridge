1. 생성형 AI 기본 활용

내 작품·아이디어를 무엇으로 확장할지 문제 정의에서 출발해, 도구 지도와 프롬프트 주문서(RTCFE)를 익히고 작품 소개글·이미지·슬라이드 개요까지 만든다.

나. 필요 지식 — 필수 15

A. AI와 대화 기본
  1. 생성형 AI (LLM) — 말귀 밝은 만능 조수입니다. 시키는 일은 뭐든 해 보지만 내 작품과 내 사정은 전혀 모릅니다. 일을 시킬 때 내 작품 이야기를 알려주는 것이 전부입니다.
  2. 프롬프트 = 주문서 (RTCFE 5슬롯) — "작품 소개글 써줘"로는 남의 얘기가 나옵니다. 프롬프트는 주문서 — 역할·목표·맥락·형식·예외를 적을수록 내 작품 이야기가 됩니다.
  3. 다시 시키기 (반복 개선) — "더 짧게", "덜 과장되게", "내 말투로"처럼 이어서 고쳐 달라고 하면 됩니다. 다시 시켜도 돈이 들지 않습니다.
  4. "왜?"라고 묻기 (탑다운 학습) — 결과를 그대로 받지 마세요. "왜 이렇게 썼어?", "다른 방법은?"이라고 되묻는 순간 AI는 선생님이 됩니다.
  5. 조심할 것 3가지 (환각·개인정보·저작권) — 첫째, AI는 그럴듯한 거짓말을 합니다 — 사실 확인 필수. 둘째, 주민번호·계좌 같은 개인정보 입력 금지. 셋째, 남의 작품·사진을 AI에 넣어 흉내 내지 않습니다.
B. 작품을 말로 옮기기
  1. 보는 사람 한 명 (타깃·페르소나) — 모두에게 쓰면 아무에게도 안 읽힙니다. 내 작품을 처음 볼 한 사람을 떠올리고 그 사람에게 말 걸듯 씁니다.
  2. 작품 한 줄 (핵심 문장) — 작품 소개는 한 문장에서 시작합니다. 무엇을 · 어떤 재료로 · 왜 — 이 셋이 든 한 줄이 모든 글의 뼈대입니다.
  3. 나만의 강점 (USP) — 옆 작가가 따라 못 하는 것 하나 — "손으로 마감한 옻칠", "실제 집사 경험" 같은 나만의 강점이 글의 중심이 됩니다.
  4. 소개글의 뼈대 (후킹 → 작품 → 행동 유도) — 첫 문장에서 눈길 → 작품·소식 → 마지막에 할 일 한마디. 이 3단 뼈대만 지키면 어떤 글도 기본은 합니다.
C. 채널별 핵심
  1. 인스타그램의 문법 — 인스타는 사진 + 짧은 글 + 해시태그. 해시태그는 내가 아니라 보는 사람이 검색할 말로 답니다(#원목트레이 #신혼집인테리어).
  2. 유튜브·숏폼의 문법 — 첫 3초에 결정됩니다. 만드는 과정과 완성 순간이 예술 콘텐츠에서 가장 잘 통하는 장면입니다.
  3. 블로그·포트폴리오에서 찾아지려면 — 사람들은 "재료 + 작품 종류"로 검색합니다. 제목에 그 검색어를 넣고, 본문에 과정과 연락 방법을 명확히 씁니다.
  4. 전시·판매 현장의 글 — 현장에서는 200자 카드 한 장이 작품 옆에서 말합니다. 작품 설명 카드와 구매·문의 안내가 한 세트입니다.
D. 도구 지도
  1. 도구는 다섯, 원리는 하나 — 챗GPT·제미나이·클로드·Genspark·Perplexity — 이름은 달라도 주문서(RTCFE)는 같습니다. 오늘 만든 프롬프트는 어느 도구에 붙여도 통합니다.
  2. 텍스트 → 이미지 → 영상 → 슬라이드 (산출물 계보) — 한 번 정리한 작품 한 줄이 소개글 → 이미지 프롬프트 → 영상 대본 → 발표 슬라이드로 이어집니다. 다시 쓰는 게 아니라 바꿔 쓰는 것입니다.

A. 제품 만들기 기본
  1. 디자인씽킹 5단계 (공감 → 정의 → 아이디어 → 시제품 → 테스트) — 내가 만들고 싶은 것보다 쓸 사람의 불편에서 출발합니다. 공감 → 정의 → 아이디어 → 시제품 → 테스트를 한 바퀴 돌면 팔리는 제품이 됩니다.
  2. 시제품 (MVP) — 완벽한 제품이 아니라 반응을 확인할 최소한의 것이 시제품(MVP)입니다. 이미지 한 장, 샘플 하나, 선주문 페이지면 충분합니다.

B. 팔리는 글의 구조
  1. 상세페이지의 뼈대 (후킹 → 문제 → 해결 → 스펙 → 신뢰 → 구매 유도) — 잘 팔리는 상세페이지는 순서가 같습니다. 눈길 → 고객의 불편 → 우리 제품 → 재료·크기 → 믿을 근거 → 사는 법.
  2. 원가와 가격 — 가격은 감이 아니라 더하기입니다. 재료 + 인건 + 포장·배송 + 수수료 + 남길 이익.
  3. 신뢰 요소 (제작 과정·소재·인증) — "좋아요"보다 "국산 자작나무, 손 옻칠 3회"가 팔립니다. 확인 가능한 사실이 신뢰입니다.
C. 판매 경로별 핵심
  1. 스마트스토어·자사몰에서 찾아지려면 — 손님은 "재료 + 제품"으로 검색합니다(원목 트레이, 은 반지). 제목과 본문에 그 검색어가 있어야 보입니다.
  2. 크라우드펀딩의 문법 — 펀딩은 제품보다 만든 사람의 이야기를 삽니다. 왜 만들었나 → 어떻게 만드나 → 무엇을 드리나.
  3. 인스타그램·릴스의 문법 — 제품 사진 한 장과 만드는 과정 15초가 가장 잘 통합니다. 해시태그는 손님이 검색할 말로.
  4. 편집숍·플리마켓의 글 — 현장에서는 제품 카드 한 장이 대신 말합니다. 이름·재료·크기·가격·관리법을 150자 안에.

  2. 컨셉 이미지 프롬프트 슬롯 — 시제품 이미지는 말로 그리는 설계도입니다. 주제·스타일·구도·조명·카메라·색감·제외·출력 슬롯을 채우면 됩니다.

A. IP 세우기
  1. IP란 무엇인가 (캐릭터·세계관·스토리) — 한 편의 그림이 아니라 계속 꺼내 쓸 수 있는 원천이 IP(지식재산)입니다. 캐릭터·세계관·스토리 셋이 갖춰지면 웹툰도 굿즈도 라이선싱도 거기서 나옵니다.
  2. 캐릭터 시트 (외형·성격·말버릇·금기) — 캐릭터는 한 장짜리 이력서가 있어야 흔들리지 않습니다. 외형·성격·말버릇·절대 하지 않는 것 네 칸.
  3. 세계관 한 줄 — "고양이가 말을 하는 동네"처럼 규칙 하나가 세계관입니다. 규칙이 정해지면 에피소드가 저절로 나옵니다.
B. 콘텐츠 설계
  1. 숏폼 대본 3단 (후킹 3초 → 본론 → 행동 유도) — 첫 3초에 멈추게 하고, 본론은 한 가지만, 마지막에 할 일 한마디(팔로우·다음 회·링크).
  2. 시리즈 설계 (주기 · 회차 · 시즌) — 한 편의 대박보다 같은 요일에 오는 한 편이 채널을 만듭니다. 주기·회차·시즌을 먼저 정합니다.
  3. 썸네일과 제목 — 내용이 아니라 썸네일과 제목이 클릭을 결정합니다. 한 장면 + 큰 글자 3~5자.
  4. 수익화 모델 다섯 가지 — 콘텐츠의 돈은 다섯 갈래에서 옵니다. 광고 · 후원 · 굿즈 · 라이선싱 · 의뢰. 처음엔 하나만 고릅니다.
C. 플랫폼별 핵심
  1. 인스타그램의 문법 — 이미지 1장 + 짧은 글 + 해시태그. 저장이 많은 글이 더 퍼집니다.
  2. 유튜브·숏폼의 문법 — 숏폼은 첫 3초, 롱폼은 제목·썸네일. 둘 다 시청 지속 시간이 노출을 정합니다.
  3. 웹툰 플랫폼의 문법 — 플랫폼마다 컷 규격·회차 분량·연재 규정이 다릅니다. 공식 가이드를 먼저 읽습니다.
  4. 크리에이터 플랫폼의 문법 — 후원·구독형 플랫폼은 팬 한 사람에게 말 겁니다. 왜 후원해야 하는지가 소개글에 있어야 합니다.

나. 필요 지식 — 필수 12

A. 작가를 말로 옮기기
  1. 작가노트와 바이오의 차이 — 작가노트는 "왜·어떻게 만들었나"를 1인칭으로, 바이오(작가 소개)는 이력·활동을 3인칭으로. 둘을 섞으면 어느 쪽도 안 됩니다.
  2. 작품 한 줄 (주제 · 재료 · 질문) — 모든 글의 뼈대는 한 문장입니다. 무엇을 · 어떤 재료로 · 어떤 질문을.
  3. 포트폴리오 한 장의 구성 — 포트폴리오는 같은 한 장의 반복입니다. 사진 1 + 제목·재료·크기·연도 + 한 줄 + 연락처.
B. 작품을 사업으로 잇기
  1. 작품 가격 책정 — 가격은 감이 아니라 기준입니다. 크기(호수) · 재료비 · 제작 시간 · 경력 · 에디션 수.
  2. 아트굿즈 계보 (원화 → 프린트 → 굿즈) — 한 점의 원화가 프린트·엽서·포스터·아트토이로 이어집니다. 원화의 가치를 지키는 순서가 있습니다.
  3. 콜라보·라이선싱 제안서의 구조 — 제안서는 A4 한 장입니다. 나는 누구 → 무엇을 함께 → 상대가 얻는 것 → 조건.
C. 채널별 핵심
  1. 갤러리·아트페어의 글 — 전시에서는 서문 3문단과 작품 카드가 작가 대신 말합니다. 관람객은 카드를 3초 읽습니다.
  2. 온라인 작품 판매의 문법 — 화면 너머 구매자는 재료·크기·에디션·보관법을 알아야 삽니다. 사진 3장 + 사실.
  3. 인스타그램의 문법 — 작품 사진 + 과정 15초 + 짧은 글. 저장이 많은 글이 퍼집니다.
  4. 기업·공공 콜라보 제안의 문법 — 제안은 상대가 얻는 것부터 씁니다. 내 작품 자랑이 아니라 상대의 공간·고객에 무엇이 좋아지는가.
D. 권리와 진정성
  1. 저작권 · 에디션 · AI 사용 고지 — 내 작품의 권리는 내가 지킵니다. 에디션 수를 밝히고, AI를 어디에 썼는지 스스로 정한 기준대로 밝힙니다.
  2. 진정성 — 부풀리지 않기 — 작품에 없는 의미를 AI가 그럴듯하게 붙여 줍니다. 내가 실제로 한 것만 남깁니다.

1. 문제 인식 (Problem)
가. 아이템의 배경과 필요성

심사위원이 보는 것 — 왜 지금 이 아이템이 필요한가를 봅니다. 개인의 관심이 아니라 고객의 문제와 그 크기에서 출발했는지, 그리고 그 문제를 작성자가 직접 겪거나 확인했는지를 봅니다.

넣을 것
  • 고객이 겪는 구체적 문제 장면 1~2개
  • 문제가 생기는 원인
  • 기존 방법(경쟁·대안)이 왜 부족한지
  • 작성자가 이 문제를 발견하게 된 경험·관찰
빼야 할 것
  • 시장이 크다는 말만 반복
  • 출처 없는 통계
  • "많은 사람이 원한다" 같은 막연한 주장

분량 — 3~4문단, 600~800자

나. 목표 시장(고객) 현황

심사위원이 보는 것 — 누가 사는가를 봅니다. 시장 전체 규모보다 "첫 고객 한 사람"이 누구이고 어디에 몇 명쯤 있는지, 그들이 지금 무엇에 돈을 쓰는지를 봅니다.

넣을 것
  • 첫 고객(페르소나) 한 사람의 구체적 묘사
  • 그 고객이 모여 있는 곳(채널·장소)
  • 고객이 지금 쓰는 대안과 지불하는 금액
  • 검증한 사실(설문·인터뷰·사전 반응)이 있으면 숫자와 함께
빼야 할 것
  • 조 단위 시장 규모만 인용
  • 모든 연령·모든 사람을 고객으로
  • 출처 없는 비율

분량 — 2~3문단 + 표 1개(고객·대안·지불 금액)

2. 실현 가능성 (Solution)
가. 아이템 현황과 차별점

심사위원이 보는 것 — 지금 어디까지 만들어져 있는가와 왜 이것이어야 하는가를 봅니다. 아이디어 단계인지 시제품이 있는지, 차별점이 고객의 문제와 연결되는지를 봅니다.

넣을 것
  • 현재 준비 정도(아이디어/시제품/판매 경험)를 사실대로
  • 핵심 기능·구성 3가지
  • 경쟁·대안과 비교한 차별점 — 고객 문제와 연결해서
  • 시제품·작품 이미지(첨부)
빼야 할 것
  • 차별점을 "품질이 좋다·감성적이다"로 끝내기
  • 준비 정도 부풀리기
  • 기능 나열만

분량 — 2~3문단 + 비교표 1개 + 이미지 1~2장

나. 실현·구체화 방안

심사위원이 보는 것 — 지원 기간 안에 무엇을 어떻게 만들 것인가를 봅니다. 단계·일정·필요 자원이 구체적인지, 작성자가 할 수 있는 일과 외부에 맡길 일을 구분했는지를 봅니다.

넣을 것
  • 개발·제작 단계 3~5개와 각 단계의 산출물
  • 월 단위 일정표
  • 필요한 장비·재료·외주(제조처·인쇄·촬영)
  • 위험 요소와 대응(재료 수급·납기·품질)
빼야 할 것
  • "열심히 하겠다" 같은 다짐
  • 일정 없는 계획
  • 외주 비용을 빼먹은 계획

분량 — 단계표 1개 + 일정표 1개 + 위험 대응 3줄

3. 성장 전략 (Scale-up)
가. 비즈니스 모델과 수익 창출 계획

심사위원이 보는 것 — 돈이 어디서 어떻게 들어오는가를 봅니다. 가격·원가·판매 경로·수수료가 맞물려 이익이 남는지, 첫 매출을 어떻게 낼지를 봅니다.

넣을 것
  • 수익 모델(판매·구독·라이선싱·수업 등) 1~2개
  • 가격과 원가 구조(재료·인건·포장·수수료)
  • 판매 경로와 각 경로의 수수료
  • 첫 12개월 매출 목표와 근거(단가 × 수량)
빼야 할 것
  • 근거 없는 매출 전망
  • 수수료·배송비를 뺀 계산
  • 수익 모델 다섯 개를 다 하겠다는 계획

분량 — 비즈니스 모델 캔버스 요약 + 원가·가격표 + 12개월 매출 표

나. 시장 진입과 성과 창출 전략

심사위원이 보는 것 — 첫 고객을 어떻게 만나는가를 봅니다. 채널·메시지·일정이 구체적인지, 파트 1·2에서 만든 콘텐츠·이미지가 실제 계획에 들어 있는지를 봅니다.

넣을 것
  • 진입 채널 1~2개와 그 이유(고객이 모인 곳)
  • 핵심 메시지 한 줄(파트 1·2 소개글 활용)
  • 월별 실행 계획(콘텐츠·이벤트·판매)
  • 성과 지표(팔로워·문의·판매 수)와 목표치
빼야 할 것
  • "SNS 마케팅을 하겠다"로 끝내기
  • 모든 채널을 다 하겠다는 계획
  • 지표 없는 계획

분량 — 채널·이유 → 메시지 → 월별 계획표 → 지표 표

다. 자금 소요와 조달 계획

심사위원이 보는 것 — 얼마가 어디에 필요하고 어디서 오는가를 봅니다. 지원금 사용 항목이 공고의 허용 항목과 맞는지, 자부담·기타 조달이 현실적인지를 봅니다.

넣을 것
  • 항목별 소요 자금(재료·제작·장비·마케팅·인건)과 산출 근거
  • 조달 계획(지원금·자부담·기타)
  • 지원금 사용 항목이 공고 규정에 맞는지 확인 표시
  • 집행 일정
빼야 할 것
  • 근거 없는 총액
  • 공고에서 허용하지 않는 항목
  • 자부담 0원

분량 — 소요 자금 표 + 조달 표 + 집행 일정 3줄

4. 팀 구성 (Team)
가. 대표자 역량

심사위원이 보는 것 — 이 사람이 이 일을 해낼 수 있는가를 봅니다. 전공·수상·경력보다 이 아이템과 직접 연결되는 경험(만들어 본 것, 팔아 본 것, 배운 것)을 봅니다.

넣을 것
  • 아이템과 직접 연결되는 경험 2~3개(제작·판매·전시·교육)
  • 보유 기술·자격·수상은 사실대로
  • 부족한 역량과 보완 방법(멘토·협력·교육)
빼야 할 것
  • 이력 나열만
  • 아이템과 무관한 자랑
  • 부족한 점 숨기기

분량 — 2문단, 400~600자

나. 팀원·협력 파트너 (선택)

심사위원이 보는 것 — 혼자가 아니라면 누가 무엇을 맡는가, 혼자라면 무엇을 누구에게 맡길 것인가(제조처·디자이너·멘토)를 봅니다.

넣을 것
  • 팀원별 역할과 아이템 관련 경험
  • 외부 협력 파트너(제조·디자인·유통·멘토)와 협력 형태
  • 아직 없는 역할과 확보 계획
빼야 할 것
  • 이름만 나열
  • 확정되지 않은 사람을 확정처럼
  • 역할 중복

분량 — 역할표 1개 + 협력 파트너 3줄

5. 첨부
가. 이미지·소개 영상·별도 양식

심사위원이 보는 것 — 첨부는 본문의 주장을 증거로 만드는 것입니다. 시제품·작품 이미지, 판매·전시 사진, 소개 영상 링크가 본문 항목과 연결돼야 합니다.

넣을 것
  • 시제품·작품 이미지 2~4장(항목 번호 표기)
  • 판매·전시·반응 증거(사진·캡처)
  • 소개 영상 링크(선택, 1~2분)
  • 공고가 요구하는 별도 양식·증빙
빼야 할 것
  • 본문과 무관한 이미지
  • 저작권·초상권이 정리되지 않은 사진
  • 분량·파일 형식 규정 무시

분량 — 공고 규정에 따름 — 원문 확인

다. 제출 전 검증

  • ☐ 모든 숫자에 근거가 있거나 [근거 필요] 표시가 남아 있지 않다
  • ☐ "최고·유일·혁신적" 같은 근거 없는 형용사를 뺐다
  • ☐ 다른 사업계획서에서 옮긴 문장이 없고, AI 초안을 내 문장으로 고쳤다
  • ☐ 공고의 제출 항목·분량·배점·지원금 허용 항목을 원문과 대조했다
  • ☐ 첨부의 저작권·초상권이 정리됐고 파일 형식·용량 규정을 확인했다

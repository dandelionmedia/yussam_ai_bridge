1. 생성형 AI 기본 활용

3시간

내 작품·아이디어를 무엇으로 확장할지 문제 정의에서 출발해, 도구 지도와 프롬프트 주문서(RTCFE)를 익히고 작품 소개글·이미지·슬라이드 개요까지 만든다.

  1. 가.문제 정의25분내 작품을 콘텐츠·제품·브랜드·서비스 중 무엇으로 확장하고 싶은가, 걸림돌, AI 경험
  2. 나.필요 지식35분생성형 AI(LLM) · 프롬프트=주문서(RTCFE) · 도구 지도(다섯 도구가 주로 하는 일, 무료/유료) · 다시 시키기 · "왜?" 묻기 · 환각·개인정보·저작권
  3. 다.실습 150분작품 소개글(작가노트·제품 설명·채널 소개 중 택1)을 기본 → 전문 → 인터뷰형으로
  4. 라.실습 240분같은 내용으로 이미지 1장 + 발표 슬라이드 개요
  5. 마.검증15분사실 확인 · 과장 · 저작권 · 초상권 체크
  6. 바.자산화15분프롬프트 보관, 다음 시간까지 과제(작품 사진 1장 준비)

2. 트랙별 특화 활용

3시간트랙별

뼈대는 같고 진단·지식·실습·예시가 트랙별로 다르다. 대표 업종의 취업·창업에 바로 쓰는 AI 활용 역량을 키운다.

  1. 가.문제 정의25분디자인·제조: 어떤 제품을 누구에게 어떤 경로로 / 콘텐츠: 어떤 IP를 어느 채널에 무엇으로 수익화 / 창작작가: 어떤 작가 브랜드를 어느 시장에 무엇으로 확장
  2. 나.필요 지식35분트랙별 필수 지식 12~20 — 시제품·상세페이지·제조 리서치 / IP·캐릭터 시트·숏폼 구조·수익화 / 작가노트·포트폴리오·라이선싱·전시 채널
  3. 다.실습 150분제품 컨셉 → 상세페이지 카피 / IP 설정 → 캐릭터·세계관 문서 / 작가노트 → 브랜드 소개문
  4. 라.실습 240분시제품 이미지 + 리서치 / 숏폼 대본 → 영상 안내 + 썸네일 / 아트굿즈 목업 + 콜라보 제안서 개요
  5. 마.검증15분과장·효능·원산지·유사 디자인 / 저작권·초상권·플랫폼 규정 / 저작권·진정성·AI 사용 고지
  6. 바.자산화15분프롬프트·이미지 보관, 파트 3의 재료로

3. 창업 사업계획서 작성

3시간

목표 지원사업을 정하고, PSST(문제·해결·시장·팀) 구조로 파트 1·2 산출물을 넣어 사업계획서 초안과 발표 슬라이드 골격을 만든다.

  1. 가.문제 정의25분어떤 지원사업·어떤 심사 기준을 겨냥하는가 — 목표 공고 1개
  2. 나.필요 지식35분사업계획서 4단 구조(PSST) · 비즈니스모델 캔버스 · 정부 창업지원사업 읽는 법 · 심사위원 관점 · 숫자로 말하기
  3. 다.실습 150분AI 인터뷰형으로 사업계획서 초안 (파트 1·2 산출물 투입)
  4. 라.실습 240분발표 슬라이드 10장 골격 + 1분 피칭 대본
  5. 마.검증15분근거 없는 숫자 · 과장 · 표절 · 심사 항목 누락
  6. 바.자산화15분제출용 DOCX·PPT 내려받기, 발표 준비 과제
